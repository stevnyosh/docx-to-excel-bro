Konversi Soal DOCX ke Template Excel

Unggah dokumen soal pilihan ganda (.docx), hasilnya langsung disusun ke template import yang sudah tertanam di aplikasi ini. Semua proses berjalan di browser Anda.

Hasil: Perceptual Speed Test-05-1, -2, dst.
    LabelPertanyaanOpsi 1–5 (nilai)KunciPembahasan
    • Memakai template Excel Anda (Template_Import_MULTIPLE_CHOICE_Question.xlsx) yang sudah tertanam. Status Input = 1, Type = mc, satu soal per baris mulai baris 2.
    • Nilai opsi: 1 atau 5 (sesuai pilihan Anda) untuk jawaban benar, 0 untuk salah.
    • Pembahasan ditutup baris Jawaban X (isi jawaban): seluruh baris tebal, isi dalam kurung tebal dan miring.
    • Kunci jawaban dicek ulang otomatis untuk soal pengurutan waktu (jam) dan nominal Rupiah.
